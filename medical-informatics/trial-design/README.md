## TrialDesignBench：评测 LLM 能否推荐剂量探索设计

**日期与团队：** 2026-11-09，arXiv 预印本；Yihan Hank Tang、Peng Yang、Jiayi Xin 等，宾夕法尼亚大学与得克萨斯大学 MD Anderson 癌症中心。[论文](https://arxiv.org/html/2611.12640v1) · [代码与数据](https://github.com/hanktang-research/TrialDesignBench)

**标签：** `临床试验设计` · `LLM + 决策树` · `分层评测`

**简述：** 为 617 项早期肿瘤剂量探索试验整理信息，用专家审校的决策规则建立设计类别参考标签。剂量探索设计规定如何分配受试者、收集毒性或疗效证据，以及何时停止或推荐剂量。这里预测的是设计方法类别，不是具体给药毫克数；历史实际采用的设计也不作标准答案。

**追问 | 怎么分开评测？** 这不是独立的信息抽取 benchmark。显式字段由研究者预先整理；分设「提供已核定的隐含变量」和「使用专家决策树」两项干预。五模型总体的类别平衡准确率从 30.7% 升至 53.1%（仅补隐含变量）、54.7%（仅走树）、72.8%（两项均用）。这些都是最终类别分数，不是各层独立准确率。

**追问 | LLM 和决策树各做什么？** 专家先制定规则；模型输出节点判断和理由；确定性代码把判断映射到叶节点。教学例：同为单药最大耐受剂量探索，「完成 28 天毒性观察才递增」与「允许观察未完成就递增」可能分别落入 BOIN 和 TITE-BOIN 类别。如果模型看错了递增条件，错在中间判断，不在代码路由。[论文方法](https://arxiv.org/html/2611.12640v1#S3) · [走树代码](https://github.com/hanktang-research/TrialDesignBench/blob/master/code/tree_walker.py)

**可借鉴：** 给显式事实、隐含判断和最终决策分别留参考答案，再逐层换入人工核定结果，定位哪一层的修正最能挽回最终错误。
