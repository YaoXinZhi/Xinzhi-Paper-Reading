## 知识图谱增强的儿童流感中成药问答

**日期与团队：** 2026-11-13，*JMIR AI*；共同一作 Haoyuan Li、Guozhen Zhao，通讯作者 Nannan Shi，中国中医科学院中医临床基础医学研究所、北京中医药大学针灸推拿学院。[论文](https://ai.jmir.org/2026/1/e101648)

**标签：** `用药知识图谱` · `指南 + RAG` · `证据溯源`

**简述：** 将 142 篇指南、共识和临床研究等文献拆成 1,294 个证据单元，经 LLM 辅助抽取和人工复核，在 Neo4j 中连接症状、证候、药品、剂量、禁忌和出处，再供问答系统检索。在 78 对可判定问答中，含无证据支持陈述的回答由单独 LLM 的 11/78 降为图谱增强系统的 0/78。研究未比较同语料的普通文本 RAG，因此不能把提升单独归因于图结构；也未验证真实临床结局。

**可借鉴：** 将每条用药主张绑定到**证据片段、适用人群或条件、来源和证据等级**，而不只挂一个文献链接。不同来源的剂量或推荐冲突应分开保留；用同一语料对比文本 RAG 和 KG-RAG，才更容易看清图结构的贡献。

**交叉阅读：** [Starling](../evidence-and-knowledge/README.md#starling)提供大规模抽取药物证据和保留实验条件的方法，但不直接交付用药知识图谱。
