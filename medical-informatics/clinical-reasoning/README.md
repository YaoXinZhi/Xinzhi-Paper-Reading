## BELIEF：用贝叶斯更新和按需检索做鉴别诊断

**日期与团队：** 2026-10，EMNLP 主会。共同一作 Mengyao Guo、Shufang Xie 来自中国人民大学，通讯作者 Rui Yan 来自武汉大学；另有 MBZUAI、KAUST 与企业合作者，工作聚焦文本医疗推理和检索增强。[论文](https://aclanthology.org/2026.emnlp-main.1678/) · [全文](https://aclanthology.org/2026.emnlp-main.1678.pdf)

**标签：** `临床推理` · `医学 RAG` · `动态检索` · `不确定性`

**简述：** 先给候选诊断分配先验权重，再依据病例证据做贝叶斯式更新。若更新后概率分布仍分散（高熵），系统就针对难以区分的候选检索外部医学证据，再更新排序。论文在 7 个文本基准和两个 7–8B 模型上评测；例如 MIMIC-C 上，BELIEF-Llama3.1-8B 的首选诊断准确率为 58.32%，去掉动态检索后为 56.33%。没有真实临床验证，框架里的权重也不能直接当作已校准的患者患病概率。

**可借鉴：** 让检索围绕「哪条证据能区分当前候选」，并记录触发原因、检索证据和排序变化。评测时除准确率外，可分别看漏检索、检索成本和证据是否改变了结论。可对照 [ChronoEvo](../guidelines-rag/README.md#chronoevo)：前者问何时需要找证据，后者问新版证据到手后是否落实。
