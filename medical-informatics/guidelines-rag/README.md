## ChronoEvo：发现指南更新，不等于落实更新

**日期与团队：** 2026-10-22 arXiv 首版，2026-11-09 更新至 v2；Min Zeng、Zaifu Zhan、Kai Yu、Rui Zhang，明尼苏达大学计算健康科学团队。[预印本](https://arxiv.org/html/2610.30631v2)

**标签：** `指南 + RAG` · `指南版本演进` · `临床决策评测`

**关键结论：** 团队整理了 **1,709 条指南建议修订**，把「有没有发现更新」「临床结论是否正确」「有没有完整落实更新」分开评分。即使直接给出新版指南证据，**14 个模型的更新识别率仍高于完整落实率**。例如 Qwen3-4B 三项分别为 90.8%、80.2%、58.5%。

**可借鉴：** 医学 RAG 除了测「检索到新指南没有」，还应测**变更有没有传到最终结论**。可以固定同一临床病例、替换指南版本，检查适应证、阈值、例外条件和推荐动作是否随证据正确变化。论文用直接提供新版证据的离线设置考察模型如何使用证据，不能据此评价实际检索器的表现。

**交叉阅读：** [儿童流感中成药问答](../medication-kg/README.md#pediatric-influenza-kg)也检索指南，但它关注证据溯源与问答质量，不评测指南版本变化。

[BELIEF](../clinical-reasoning/README.md#belief)把诊断不确定性用作检索开关，可与 ChronoEvo 的「证据到手后有没有落实」评测互补；它本身不评测指南更新。
