## HoloCell：面向整体细胞建模的生成式多组学模型

**日期与团队：** 2026-06-11，bioRxiv 首版；Qun Jiang、Zhen Li、Bowen Hu 等，中关村学院与清华大学等合作。[预印本](https://www.biorxiv.org/content/10.64898/2026.06.07.730684v1) · [项目](https://github.com/bjzgcai/HoloCell)

**标签：** `虚拟细胞` · `生物基础模型` · `单细胞多组学`

**简述：** 用共享 token 体系连接染色质调控元件、RNA 和蛋白，以迭代预测和重掩码补全缺失模态，评测单组学表征、多组学整合与跨模态生成。

**追问 | 已经是完整虚拟细胞吗？** 还不是。能从 RNA 补出蛋白表达，不等于能预测干预后的时间演化，更不能证明学到了真实因果机制。

## AI-DBTL：用 AI 编排哺乳动物生物设计闭环

**日期与团队：** 2026-07-06，*Nature Biomedical Engineering* 评论；Jingjing Han、Martin Fussenegger，ETH Zurich 与巴塞尔大学相关团队。[文章](https://www.nature.com/articles/s41551-026-01730-7)

**标签：** `虚拟细胞` · `科研自动化` · `DBTL`

**简述：** 建议让虚拟细胞或组织模型参与设计、构建、测试、学习每一轮：先提候选，再让实验反馈更新模型并选下一轮实验。文章提出研究路线，没有交付经过湿实验验证的完整闭环系统。

**可借鉴：** LLM 更适合整理证据和实验记录、规划任务及调用专用模型。闭环成效宜用实验轮次、成本、命中率衡量，而不只看离线预测分数。
